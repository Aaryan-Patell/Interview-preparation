# Interview Practice Tracker

A simple, responsive web application to organize interview preparation questions and track learning progress.

## Features

- Add questions with title, category, difficulty, and status
- Search questions by title
- Filter by category, status, and difficulty
- Update question status to Pending, In Progress, or         Completed
- Delete questions
- Track total, completed, and in-progress questions
- Calculate overall completion percentage
- Save questions using browser LocalStorage
- Responsive design for desktop and mobile devices

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage

## Setup Instructions

### Prerequisites

- A modern web browser
- Visual Studio Code
- Live Server extension (optional)

### Steps

- Open the project folder in Visual Studio Code.
- Open index.html in your browser.
- Alternatively, right-click index.html and select Open with Live Server.
- Start adding and managing interview questions.

## Assumptions

- The application uses HTML, CSS, and JavaScript only.
- Questions are stored in browser LocalStorage.
- Data is not synchronized across browsers or devices.
- Clearing browser site data may remove saved questions.
- Available categories are DSA, Git, and Technical.
- Available difficulty levels are Easy, Medium, and Hard.
- Available statuses are Pending, In Progress, and Completed.
- Progress is calculated based on completed questions.
- Dashboard statistics show all questions, regardless of active filters.
- The application does not include authentication or cloud storage.
